# Smart Interview Preparation App

An intelligent full-stack application designed to help users prepare for technical interviews efficiently. It offers categorized questions, quizzes, and leverages a machine learning model to automatically classify questions based on their text.


## Features Completed
### Authentication
- **User Signup/Login** using **FastAPI backend**
- **JWT-based Authentication**
- Secure password hashing with `bcrypt` (`passlib`)
- PostgreSQL used to store user information


## Tech Stack

### Backend:
- **FastAPI** (Python framework)
- **SQLAlchemy** ORM
- **PostgreSQL** (Relational database)
- **JWT** for authentication
- **passlib** for secure password hashing
- **python-jose** for JWT encoding/decoding

### Machine Learning (Coming Next):
- **Scikit-learn** (text classification)


### Frontend (Planned):
- **React.js** (UI for quiz/dashboard)
- **Axios** for API communication
- **Tailwind CSS** (for styling)
